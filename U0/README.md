# U0 ｜ 看懂檔案結構：這包東西到底是什麼

> **這堂不是寫程式，是先看懂你手上這包是什麼。**
> 一個 zip 解開一堆資料夾、一堆沒看過的副檔名——**先有地圖，再開始動手。**

約 **30–40 分鐘**。做完再進 U1。

## 為什麼要有這一堂

你等一下會照著講義改檔案、下指令，那些都做得完。
但如果你**不知道自己在動什麼**，換一個專案就要從頭再來一次。

所以 U0 要給你的**不是這份專案的答案，是一套判斷方法**：

> **先刪掉不用看的 → 再從名字猜用途 → 猜不到就找 README。**

這三步在任何一個別人寫的專案上都成立。

## 今天照這個順序做

| 順序 | 檔案 | 你會完成什麼 |
|---|---|---|
| 1 | [`STEP-01-read-the-tree.md`](./STEP-01-read-the-tree.md) | 用三條規則，把一萬多個檔案縮成十幾個 |
| 2 | [`STEP-02-naming-rules.md`](./STEP-02-naming-rules.md) | 看懂資料夾名、檔名關鍵字、副檔名；搞懂 `.env` 為什麼不給你 |
| 3 | [`STEP-03-this-project.md`](./STEP-03-this-project.md) | 自己判斷三題，然後看懂整份專案的地圖 |

**你需要**：把 zip 解壓縮，用 VS Code 打開最外層那個資料夾。**這一堂還不會下任何 Git 指令。**

## U0 要學會的三條規則

1. **名字開頭是 `.` 的，是給工具看的**，不是給你的 → 先跳過
2. **「自動長出來的」不用看**（`node_modules/`、`dist/`）→ `.gitignore` 就是那張清單
3. **全大寫的 `.md` ＝「請先讀我」** → 進到陌生資料夾，第一件事是找 `README.md`

加上兩個判斷法：

- **名字有沒有對應到某個工具？** 有 → 全世界通用，查得到；沒有 → 專案自己取的，只能讀 README
- **這個檔案裡有沒有「只有我才有」的東西？** 有 → 它不該進 Git（密碼、金鑰）

## 速查表一：副檔名

> **不用背。** 每個都在 STEP-02 講過，這張表是給你**中途卡住時回來查的**。

| 副檔名 | 是什麼 | 給誰 |
|---|---|---|
| `.md` | 說明文件（這份專案最多的就是它） | 人 |
| `.csv` | 表格存成純文字，Excel 打得開 | 人 |
| `.json` | 設定和資料 | 程式 |
| `.yml` | 設定（GitHub Actions 用） | 程式 |
| `.js` / `.jsx` | JavaScript 程式（`.jsx` 裡面還夾著畫面長相） | 會被執行 |
| `.py` | Python 程式 | 會被執行 |
| `.ts` / `.mjs` / `.astro` | 也是程式，不同寫法 | 會被執行 |
| `.html` | 網頁骨架 | 畫面 |
| `.css` | 網頁外觀 | 畫面 |
| `.svg` | 用文字描述的圖片 | 畫面 |
| `.bat` | 雙擊就跑一串指令（Windows） | 電腦執行 |
| `.command` | 雙擊就跑一串指令（macOS） | 電腦執行 |

> ⚠️ **`.bin`、`.vite`、`.env`、`.gitignore` 都不是副檔名**，
> 它們**點的前面什麼都沒有**，整個就是名字本身。

## 速查表二：名字裡的關鍵字

| 看到 | 通常代表 | 這份專案裡 |
|---|---|---|
| `README` | 「讀我」：這一層的說明 | 根目錄、`U1/`、`blog-lab/`、`ops-agent-lab/` 各有一份 |
| `config` | 設定：改它會影響整個工具怎麼跑 | `vite.config.js`、`astro.config.mjs` |
| `ignore` | 忽略清單：「這些不要管」 | `.gitignore` |
| `example` / `sample` / `template` | **範本，不是真的那個** | `.env.example`、`inventory_sample.csv`、`report_template.json` |
| `lock` | 鎖住版本，機器產生的，別手改 | `package-lock.json` |
| `src` | source ＝ 人寫的原始碼 | `web-lab/src/` |
| `public` / `static` | 直接對外公開的檔案 | `web-lab/public/` |
| `frontend` / `client` | 使用者**看得到**的畫面那一半 | 這份專案叫 `web-lab/` |
| `backend` / `server` / `api` | 使用者**看不到**、背後跑的那一半 | U3 會遇到 |
| `.env` | **密碼和金鑰**。絕對不進 Git | `line-lab/.env`（你看不到它，是刻意的） |
| `node_modules` | 從網路下載的現成程式，一萬多個檔案 | 跑過 `npm install` 才會出現 |
| `dist` | 打包好的成品 | 跑過 `npm run build` 才會出現 |
